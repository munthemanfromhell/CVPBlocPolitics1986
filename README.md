# Bloc Politics: The Christian People's Party

A native Dynamic Social Democracy election-viewer mockup depicting the March 1986 snap Reichstag election in a surviving German Republic, played from the perspective of the Christian People's Party.

## Upload

Upload both of these files to the root of `munthemanfromhell/CVPBlocPolitics1986`:

- `CVPBlocPolitics1986_v1.json`
- `bloc_politics_background.png`

Enable GitHub Pages from the `main` branch and repository root.

Load the mod through Dynamic's Mods screen with:

`https://munthemanfromhell.github.io/CVPBlocPolitics1986/CVPBlocPolitics1986_v1.json`

## Contents

- Immediate predetermined election
- Native 600-seat D3 Reichstag chamber
- Full election table with vote and seat changes
- Three available government outcomes and two locked alternatives
- No sidebars
- Supplied state map as the background
- Full Library menu with all original categories and a restart option
- Fixed-state 1986 Library pages for government, parties, demographics, opinion, organisations, factions and figures

The Library preserves Dynamic's menu structure and core constitutional explanation. State-dependent pages are rendered for the fixed 1986 mockup rather than retaining the original game's conditional variables.
